DeadlineDesk

Aryan Gupta (1024030764, agupta_be24@thapar.edu) · Aksh Goyal (1024030766, agoyal2_be24@thapar.edu) · Naveen Bansal (1024030767, nbansal3_be24@thapar.edu)

Placement rounds and assignment cutoffs are scattered across informal channels. DeadlineDesk provides a placement track (companies, checklists, reminders) and an academic dropbox (submit, late policy, similarity stub, TA grade) in one role-based web system.

Objectives (W7)

  • Auth for Student / TA / Placement Admin
  • Placement: round + checklist + reminder log
  • Academic: submit + late flag + grade
  • ≥5 automated late-policy tests

Roles

  • Aryan — architecture, CI, placement
  • Aksh Goyal — academic module, tests
  • Naveen — UI, docs site, demo
