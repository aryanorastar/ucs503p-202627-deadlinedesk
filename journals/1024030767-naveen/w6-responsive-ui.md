# Week 6: Responsive Role Portals

## Objective

Turn the approved flows into consistent, responsive server-rendered pages.

## Work completed

- Built the shared navigation, message stack, footer, and generic form page.
- Built role-specific dashboard content and empty states.
- Built placement list/detail, assignment list/detail, and submission record pages.
- Added light/dark color tokens using system preference.
- Added 800 px and 520 px collapse rules for grids, headers, forms, and navigation.
- Added reduced-motion and reduced-transparency fallbacks.

## Design constraint

The interface favors readable records and clear state over animation. This keeps the prototype stable during evaluation and on lower-power devices.
