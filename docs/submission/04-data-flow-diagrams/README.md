# Data-Flow Diagrams

The Level 0 context diagram treats DeadlineDesk as one process. The Level 1 diagram decomposes it into authentication, Placement Track, Academic Dropbox, and reminder/audit processes with their persistent stores.

For each level, the supplied [Level 0 PDF](https://github.com/aryanorastar/ucs503p-202627-deadlinedesk/blob/master/project-proposal/figures/dfd-level-0.pdf) or [Level 1 PDF](https://github.com/aryanorastar/ucs503p-202627-deadlinedesk/blob/master/project-proposal/figures/dfd-level-1.pdf) is the submission-ready diagram and the PNG is the raster export used by the proposal. The canonical files are maintained once in `project-proposal/figures/`.

Arrows describe data movement, not interface navigation or execution order.
