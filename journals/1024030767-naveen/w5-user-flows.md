# Week 5: User Flows and Interface System

## Objective

Map each role to a short, demonstrable interface path.

## Work completed

- Defined Student, TA, and Placement Admin navigation and dashboards.
- Reduced Week 7 placement flow to round detail, checklist completion, and readiness.
- Reduced academic flow to assignment detail, upload outcome, review, and grade.
- Defined empty, error, success-message, and permission-denied states.
- Chose an institutional navy/amber token system with semantic form patterns.

## Accessibility considerations

Labels remain above inputs; forms use native controls and CSRF; visible focus, skip link, semantic headings, and keyboard navigation are included.
